# 훈련 일지 후속 범위

## 1. 목적

- 이번 작업에서 제외한 후속 기능과 백로그를 별도 관리한다.
- 메인 문서 `training-log-product-plan.md`는 이번 작업 범위만 유지한다.

## 2. 다음 작업 우선순위

### 2.1 높은 우선순위

- 하루 다회차 세션 분리
- 성장 이벤트 다중 이미지 첨부
- 기술 해시태그 통계
- 주간/월간 회고 요약

### 2.2 중간 우선순위

- 훈련 리마인드 푸시
- 이벤트 타입 추가 확장
- 체크리스트 템플릿화
- 프로필 공개형 성장 히스토리

### 2.3 낮은 우선순위

- 친구 공유
- 코치 피드백
- 외부 건강 앱 연동
- 커뮤니티 글 자동 변환

## 3. 이번 작업에서 제외한 항목

- 관리자 검수 화면
- 공개 피드형 타임라인
- 좋아요/댓글/공유
- 출석 체크 기반 자동 기록 생성
- Apple Health, Google Fit 연동
- 다중 이미지 편집 UX

## 4. 후속 검토 포인트

- `GrowthEventType`에 새 enum을 추가할지 여부
- `GrowthEvent`를 유지한 채 타입별 서브모델로 확장할지 여부
- `TrainingSession` 세분화가 실제 사용성에 필요한지 여부
- 태그 검색과 추천을 백엔드에서 어디까지 담당할지 여부
